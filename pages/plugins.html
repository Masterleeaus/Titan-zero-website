AI UPGRADES

Priced by how much AI work each plugin does.

Every plugin has two optional hosted AI upgrades. The AI Assistant helps people with questions, drafts and suggestions. The AI Agent Team runs specialist agents that do approved work. Prices move with the AI work each plugin needs.

WorkloadAI Assistant / AI Agent Team (A$ per month, incl. GST)What it means
LightA$19 / A$79Mostly rules and data work, with occasional AI for summaries, search and drafting.
StandardA$29 / A$99Regular conversational help, drafting and suggestions for people using the plugin every day.
HeavyA$39 / A$129High-volume generation, many agent runs or content produced at scale.

Scheduling & Enquiries is set at the Standard level (A$29 and A$99). Other plugin prices are proposed and will be confirmed before launch.
